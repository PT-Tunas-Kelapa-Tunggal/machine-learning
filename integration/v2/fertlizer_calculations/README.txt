How to run?

1. Use python 3.9.x
2. Install the requirement using requirements.txt
3. Run the python file with this command 
   python fertlizer_calculations.py --image <imagefilename.jpg> --user-request-submission-json <jsoncontentinstring>

   (For user_submission_request sample, see user_submission_request.json)

4. And after the python successfully run, the output file will be in the outputs/ folder.
